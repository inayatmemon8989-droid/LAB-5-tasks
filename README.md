## Overview

This repository contains solutions for the Programming Fundamentals Lab Tasks covering control structures in C, including `if-else` statements, nested `if-else` blocks, and nested `switch` control logic.

---

## Tasks Summary

### Task 1: Temperature Status (`task1_temperature.c`)
Determines the temperature classification based on user input in Celsius:
- **Cold:** Temperature < 15
- **Normal:** 15 <= Temperature <= 30
- **Hot:** Temperature > 30

### Task 2: Mobile Data Package (`task2_mobile_balance.c`)
Checks account balance before package activation:
- **Low Balance:** Balance < 500
- **Sufficient Balance:** 500 <= Balance <= 2000
- **Premium Balance:** Balance > 2000

### Task 3: Hospital Appointment System (`task3_hospital_appointment.c`)
Uses nested `if-else` statements to check three conditions in order (`1` for Yes, `0` for No):
1. Patient appointment status
2. Doctor availability
3. Registration completion status

### Task 4: Online Food Order System (`task4_food_order.c`)
Uses nested `if-else` logic to process an order order step-by-step (`1` for Yes, `0` for No):
1. Restaurant opening status
2. Item availability
3. Customer balance sufficiency

### Task 5: ATM Menu System (`task5_atm_menu.c`)
Uses nested `switch` statements to navigate a multi-level ATM menu:
- Primary options: Balance Inquiry, Cash Withdrawal, Cash Deposit, PIN Change.
- Secondary options: Account Selection (Savings vs. Current) or confirmation prompt.
